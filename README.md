
# AHPL Exports - Full Stack Java Project

A responsive export company website developed
as a Full Stack Java learning project.

## Technologies Used

### Frontend
- React.js
- Vite
- Tailwind CSS
- Lucide React
- React Router DOM
- CSS Animations

### Backend
- Java JDK 25
- Spring Boot
- Spring Web
- REST APIs
- Maven

## Features

- Responsive website design
- Animated hero banner
- Responsive navigation menu
- Mobile-friendly layout
- Java REST API integration
- Dynamic company information

## Project Structure

AHPLExports/
backend/
frontend/
.gitignore
README.md

## Run Backend

cd backend

.\mvnw.cmd spring-boot:run

Backend URL: http://localhost:8080

## Run Frontend

cd frontend

npm install
npm run dev

Frontend URL: http://localhost:5173

## API Endpoints
